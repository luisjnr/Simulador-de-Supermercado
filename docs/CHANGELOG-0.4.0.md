# Changelog — 0.4.0

- Dia desacelerado de 8× para 5,5× (aprox. 44 segundos reais por expediente).
- NPCs mais lentos: 22–28 unidades por segundo simulado.
- Spawn diário aleatório de 20–28 clientes, distribuídos pelo expediente.
- Lista de interesses ampliada para 2–5 categorias por cliente.
- Emoji 😊 ao concluir uma compra e 😢 ao desistir da fila.
- Tolerância de fila aumentada para 65 segundos simulados.
