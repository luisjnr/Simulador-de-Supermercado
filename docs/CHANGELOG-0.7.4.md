# Changelog — 0.7.4

## Reposição de estoque ajustável

- Campo numérico para escolher quantas unidades repor, permitindo comprar apenas 1 unidade.
- Custo da reposição escolhida recalculado em tempo real.
- Mantido um botão de compra rápida de até 10 unidades.
- Quantidades limitadas pelo espaço restante no estoque.
- Os botões são desativados quando o mercado está aberto, o estoque está cheio ou o saldo é insuficiente.
- Preços e controles de reajuste permanecem inalterados.
