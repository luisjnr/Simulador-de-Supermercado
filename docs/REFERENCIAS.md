# Referências do projeto

- `documentacao-base.pdf`: documentação funcional e técnica enviada para orientar o simulador.
- `referencias/modelos-npcs-original.jpg`: folha original com os dez modelos de personagens.
- A imagem do supermercado enviada pela equipe foi usada somente como referência de composição. O mapa atual é desenhado por código em `src/game/scenes/MarketScene.ts` e não carrega a imagem original.
- `../public/assets/npcs/`: dez recortes individuais em PNG com fundo transparente, derivados da folha de NPCs.

Os recortes de NPC mantêm os desenhos originais. Eles são sprites estáticos; não foram criados quadros de animação que não existiam na referência. A operadora do caixa é desenhada separadamente em posição sentada.
